# Robotics Academy Exercises – ROS2 (C++)

This repository contains my implementations of several exercises from the **Robotics Academy** platform. The goal of this project is to practice and deepen my understanding of robotics concepts such as perception, control, and autonomous behavior through hands-on programming tasks.

The exercises are developed using **ROS2 Humble** and implemented in **C++**.

Currently, the repository is a **work in progress** and far from complete. As I progress through the Robotics Academy challenges, I will continue adding new solutions, improvements, and supporting tools.

Alongside the main exercise solutions, this repository may also include additional scripts and experimental code used to test specific components (such as perception modules or control strategies). These intermediate scripts help validate individual parts of the system before integrating them into the final solution.
